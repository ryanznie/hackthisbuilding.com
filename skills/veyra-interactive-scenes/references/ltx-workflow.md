# Optional offline LTX media workflow

Use the pinned [upstream LTX guide](https://github.com/amirmushichge/veyra-interactive-car/blob/v1.0.0/docs/LTX_API.md) for its helper's behavior, and current official [LTX documentation](https://docs.ltx.io/) for endpoint schemas, model support and pricing. This workflow produces authored media for later review; it is not a real-time building renderer.

The upstream helper `scripts/ltx-generate.mjs` supports a free local dry run, an explicit paid submission, saved job IDs and resuming an interrupted job. Inspect the script before first execution. Local input paths are resolved from the repository root. An ordinary dry run makes no network request.

For a new paid take, obtain authorization for the actual input upload and generation cost if it is not already present in the session. Store credentials in an ignored local environment file or server secret. Keep generated outputs in a separate ignored take directory and never overwrite approved media automatically.

Persist the submission marker and returned job ID. If a request may have reached the provider but no ID was saved, inspect provider history before submitting again. Resume polling/download using the existing ID rather than creating duplicate billable jobs. Download completed results because provider URLs can expire.

Review geometric consistency, registered framing and forward/reverse endpoints before incorporating media. First/last-frame fields and supported settings are provider-specific; verify the current schema rather than copying another provider's field names. Do not claim the bundled Veyra films were generated by LTX.
