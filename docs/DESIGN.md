# Design direction

Purpose: a phone-friendly public artwork control surface. A passerby previews an idea, joins the queue, then looks up.

Considered playful arcade, editorial museum, and architectural control-room directions. Chosen: architectural control room, warm charcoal and concrete, ivory type, electric chartreuse primary action. Large left-hand building visualization, right-hand composition panel, live horizontal queue beneath. Memorable element: the actual 153-window facade animates in the interface; the website feels like an instrument for the building.

Use Space Grotesk for headlines and body; IBM Plex Mono for technical labels and timing. UI is a functional workspace, not a marketing landing page. Fine rules, squared controls, quiet map/grid backdrop and restrained light glow. No gradients, fake visitor counts, or fake queue submissions. Controls 44px minimum. Visible keyboard focus. Respect reduced motion. On phones show the compact facade then prompt and personal status, with queue below.

Initial database design-system match suggested a generic hero/features pattern, which is off-target for this working tool; use the explicit product-specific direction above and the skill's accessibility guidance.
